# ربات روبیکای تری‌لند (TERI LAND)

ربات فارسی فروش و پشتیبانی قطعات یدکی تریلر، با استفاده از Bot API رسمی روبیکا و Python.

## امکانات
- پیام خوشامدگویی و منوی فارسی
- فهرست دسته‌بندی قطعات یدکی تریلر
- نمایش شماره‌های فروش: `09037882370` و `09189147468`
- لینک کانال: https://rubika.ir/Teri_land
- ثبت پیام مشتری و ارسال آن به مدیر
- پاسخ مدیر به مشتری با دستور `/reply`

## فایل‌ها
- `main.py`: برنامه اصلی
- `requirements.txt`: وابستگی‌ها
- `Procfile`: فرمان اجرا برای پلتفرم‌های میزبانی
- `.gitignore`: جلوگیری از بارگذاری فایل‌های حساس و پایگاه داده

## راه‌اندازی در Railway
1. این مخزن را در GitHub بسازید و فایل‌های پروژه را در ریشه مخزن آپلود کنید.
2. در Railway یک پروژه جدید از GitHub Repository بسازید و همین مخزن را انتخاب کنید.
3. در بخش **Variables** این متغیرها را اضافه کنید:
   - `RUBIKA_BOT_TOKEN` = توکن دریافتی از BotFather
   - `ADMIN_CHAT_ID` = شناسه چت مدیر (مراحل زیر)
4. Railway با استفاده از `Procfile` برنامه را اجرا می‌کند.

## تعیین شناسه مدیر
1. پس از اولین Deploy، در روبیکا به ربات خود پیام `/myid` بدهید.
2. ربات شناسه چت را برای شما می‌فرستد.
3. همان مقدار را در Railway در متغیر `ADMIN_CHAT_ID` قرار دهید.
4. برنامه را Restart یا Redeploy کنید.

**امنیت:** توکن را در GitHub، فایل کد یا پیام عمومی قرار ندهید. فقط در Variables/Secrets سرویس میزبانی وارد کنید. اگر توکن جایی افشا شد، از BotFather توکن تازه بگیرید.

## پاسخ‌گویی مدیر به مشتری
وقتی مشتری پیام می‌دهد، ربات یک پیام حاوی شماره پیگیری برای مدیر می‌فرستد. مدیر در چت خصوصی ربات دستور زیر را ارسال می‌کند:

`/reply ABC123 متن پاسخ شما`

به‌جای `ABC123` شماره پیگیری همان مشتری را قرار دهید.

## نکات مهم
- برنامه با روش رسمی `getUpdates` (Long Polling) پیام‌ها را دریافت می‌کند؛ برای اجرا به دامنه و وب‌هوک نیاز ندارد.
- دکمه‌های ChatKeypad استاندارد روبیکا هستند. رنگ اختصاصی برای خود دکمه‌ها در API استاندارد تعریف نشده؛ ظاهر مشکی و طلایی در متن‌ها و نمادهای منو اعمال شده است.
- کاتالوگ فعلی دسته‌بندی اولیه است و قیمت/موجودی واقعی ندارد. برای افزودن محصولات، عکس‌ها، مشخصات و قیمت‌ها باید اطلاعات محصولات را تکمیل کنید.
- پیام‌های متنی آزاد مشتری به‌عنوان درخواست پشتیبانی ثبت می‌شوند.

## اجرای محلی
```bash
python -m pip install -r requirements.txt
# Linux/macOS:
export RUBIKA_BOT_TOKEN="YOUR_TOKEN"
export ADMIN_CHAT_ID="YOUR_CHAT_ID"
python main.py
```

در Windows PowerShell:
```powershell
$env:RUBIKA_BOT_TOKEN="YOUR_TOKEN"
$env:ADMIN_CHAT_ID="YOUR_CHAT_ID"
python main.py
```
